% Abstract en castellano
\renewcommand*\abstractname{Resumen}
\begin{abstract}
  \nombreProyecto es una aplicación orientada al análisis temático
  cualitativo de los textos asociados a los \acrfull{tfg}. El objetivo
  principal es facilitar a docentes, investigadores y estudiantes la
  exploración del contenido académico, la identificación de tendencias y la
  comparación de resultados entre cursos.

  El sistema parte de un conjunto de datos construido a partir de repositorios
  públicos en GitHub, incluyendo contenido de memorias de \acrshort{tfg} en
  formato \LaTeX{}, ficheros \textit{readmes}, \textit{issues} y
  \text{abstracts}. Sobre este corpus se aplica un flujo de preprocesamiento y
  modelado de temas mediante \textbf{Latent Dirichlet Allocation
    (LDA)}~\cite{blei2003lda},
  \textbf{Top2Vec}~\cite{angelovTop2VecDistributedRepresentations2020},
  \textbf{BERTopic}~\cite{grootendorstBERTopicNeuralTopic2022} y
  \textbf{FASTopic}~\cite{2024arXiv240517978W}.

  El trabajo se centra en el diseño e implementación de la solución, así como en
  la comparación de los modelos para valorar su utilidad en un contexto académico
  real. Como resultado, se obtiene una herramienta reproducible para apoyar la
  gestión del conocimiento y el análisis de la producción académica
  universitaria.
\end{abstract}

\renewcommand*\abstractname{Descriptores}
\begin{abstract}
  Análisis temático, Topic Modeling, LDA, BERTopic, Top2Vec, FASTopic, TFG, Análisis de Datos, Procesamiento del Lenguaje Natural, Ingeniería Informática.
\end{abstract}

% Abstract en inglés
\renewcommand*\abstractname{Abstract}
\begin{abstract}
  \nombreProyecto is an application for qualitative thematic analysis of
  texts related to Final Degree Projects. Its main goal is to support teachers,
  researchers, and students in exploring academic content, identifying trends,
  and comparing results across academic years.

  The system uses a dataset built from public GitHub repositories, including
  \LaTeX{} reports, readme files, issues, and academic abstracts. A full text
  processing and topic modeling pipeline is applied using \textbf{Latent
    Dirichlet Allocation (LDA)}~\cite{blei2003lda},
  \textbf{Top2Vec}~\cite{angelovTop2VecDistributedRepresentations2020},
  \textbf{BERTopic}~\cite{grootendorstBERTopicNeuralTopic2022}, and
  \textbf{FASTopic}~\cite{2024arXiv240517978W}.

  This work focuses on the design and implementation of the solution, together
  with a comparative analysis of the selected models in a real academic setting.
  The final result is a reproducible tool that supports academic knowledge
  management and thematic exploration.
\end{abstract}
